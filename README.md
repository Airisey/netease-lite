# 网易云音乐 Lite

Windows 上的网易云音乐第三方轻量客户端。Electron + 原生 DOM，无前端框架，界面全部自绘；数据走网易云官方接口，与官方客户端同一账号。

## 功能

- **登录**：扫码（推荐）、手机号 + 验证码 / 密码、Cookie 粘贴；撞上账号级安全验证（`-462`）时弹二维码，验完自动重登。
- **歌单**：侧栏分「创建的歌单」「收藏的歌单」，支持新建、编辑、收藏、多选批量（移动到 / 添加到 / 喜欢 / 下载 / 删除）。
- **发现**：推荐歌单、每日推荐、最近播放、听歌排行、歌手页、个人主页。
- **搜索**：单曲 / 歌手 / 专辑 / 歌单 / 用户。
- **播放**：标准 / 较高 / 极高 / 无损四档；列表循环、单曲循环、随机三档；播放队列面板、进度记忆、全屏歌词（含逐行翻译）、评论。
- **下载**：能播的就能下，落盘是标准 MP3 / FLAC，MP3 写入完整 ID3v2.3 标签（含 500×500 封面）。支持断点续传（暂停 / 断网 / 杀进程后接着下同一个文件）、暂停继续、按歌手/专辑分类、命名模板。
- **本地**：「本地扫描」按标签优先、文件名兜底认歌，本地文件优先播放；「已下载音乐」按文件时间从新到旧列出本机已有的歌，「正在下载」只看未完成任务。
- **界面**：五款皮肤（经典黑 / 现代白 / 瑞士风 / 落日余晖 / 街机风）、无边框窗口、横竖两种迷你窗。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `Ctrl` + `←` / `→` | 上一首 / 下一首 |
| `↑` / `↓` | 音量 ±5% |
| `Ctrl` + `F` | 聚焦搜索框 |
| `L` | 打开 / 关闭全屏播放页 |
| `Q` | 打开 / 关闭播放队列 |
| `Esc` | 关闭队列 / 全屏页 / 弹窗 |
| 鼠标侧键 | 后退 / 前进 |

## 运行

打包版双击 `网易云音乐 Lite.exe`。源码运行：

```powershell
npm install       # 只装 Electron 运行时，无其他依赖
node scripts\start.js
```

## 构建

```powershell
node scripts\build.js [输出目录]
```

默认输出到 `D:\down\Tools\FromAI\网易云音乐 Lite`，也可以设环境变量 `NETEASE_LITE_DIST` 覆盖。构建会保留成品目录里已有的 `resources\app\data\config.json`（登录态、音质、音量），重建不掉登录。

## 登录

扫码最省事；手机号登录支持验证码和密码，密码在本地先 MD5 再发。登录态（Cookie）存在 `data\config.json`，也可以直接粘贴 Cookie。

## 项目结构

```
electron/            主进程
  main.js            窗口、neimg:// 图片代理、IPC、配置持久化
  download.js        下载队列（串行、断点续传、模板命名、分类目录）
  id3.js             给下载的 MP3 写 ID3v2.3 标签
  preload.js         contextBridge 暴露的 window.ne
  api/               weapi 加密、Cookie、全部接口与数据规范化
renderer/            渲染进程（无框架，原生 DOM + CSS 变量）
  index.html         主界面
  mini.html          悬浮小窗
  styles.css         经典黑主题
  skins.css          另外四套皮肤
  js/                播放器、各页面渲染、设置、歌词、状态与接口封装
scripts/             启动与打包脚本
```
